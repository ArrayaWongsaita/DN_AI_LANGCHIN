# Workshop 01 — เลือกเครื่องมือให้เหมาะกับงาน

## โจทย์

วิเคราะห์แอปตัวอย่าง 5 แบบด้านล่าง แล้วเลือกว่าควรใช้ **(A) เรียก LLM ตรงๆ**, **(B) LangChain** หรือ **(C) LangGraph**
พร้อมเหตุผล 1–2 ประโยค

1. ปุ่ม "สรุปบทความ" ในเว็บ — ส่งบทความครั้งเดียว ได้สรุปกลับ ใช้ provider เดียว
2. แชตบอทร้านค้าที่ต้องเรียก API ค้นหาสินค้าและเช็กสต็อก และเปลี่ยน provider ได้ในอนาคต
3. ระบบอนุมัติใบลา: AI ร่างเอกสาร → รอหัวหน้าอนุมัติ (อาจรอเป็นวัน) → ถ้าไม่อนุมัติให้วนแก้ไข
4. สคริปต์ที่แปลข้อความ 1 ประโยคเป็นอังกฤษ รันครั้งเดียวบนเครื่องตัวเอง
5. Agent ฝ่ายซัพพอร์ตที่ต้องจำสถานะลูกค้าข้ามหลายวัน มีหลายสาขาตามเงื่อนไข และมี human approval

## Requirements

- ตอบครบทั้ง 5 ข้อ เป็นไฟล์ `my-answers.md`
- แต่ละข้อระบุ A/B/C + เหตุผลที่อ้างถึง: ต้องใช้ tool? ต้องมี state/loop/เงื่อนไข? ต้องสลับ provider?
- (เสริม) รัน `pnpm play 1-3` แล้วสรุปว่า "ส่วนไหนที่ LangChain ช่วยลดโค้ด"

## Expected Output

ไฟล์ `my-answers.md` ที่มี 5 ข้อ ข้อละ 1 การเลือก + เหตุผล

## Acceptance Criteria

- [ ] ตอบครบ 5 ข้อ
- [ ] ทุกข้อมีเหตุผลที่อ้างอิงปัจจัยด้านบนอย่างน้อย 1 ข้อ
- [ ] ข้อ 3 และ 5 เลือก LangGraph พร้อมอธิบายว่าเพราะต้องมี state/interrupt/loop
- [ ] ข้อ 1 และ 4 ไม่เลือก LangGraph
